Reliafy runs on two open-source Python libraries, and you can use them on their own.

SurPyval fits life distributions to failures with suspensions, intervals and truncation: https://github.com/derrynknife/SurPyval

RePyability solves block diagrams, fault trees and the exact availability of repairable systems: https://github.com/derrynknife/RePyability

pip install surpyval repyability

Any Reliafy diagram downloads as a Python script that runs on them.
