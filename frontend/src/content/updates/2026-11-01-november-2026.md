Here's what changed in Reliafy this month. Everything below is live now.

## Use Reliafy from Claude

Reliafy now works inside Claude. In **claude.ai** (or the Claude desktop and
mobile apps), go to Settings → Connectors → Add custom connector, enter
`https://reliafy.com/mcp`, and sign in to Reliafy. In
[Claude Code](https://claude.com/claude-code) it's one command:

```
claude mcp add --transport http reliafy https://reliafy.com/mcp
```

Then just ask: "fit a Weibull to these failure times, treating the last one as
still running", "what's the reliability of my pump model at 2,000 hours?",
"build an RBD of this conveyor with the A/B actuators redundant and give me the
Python for it". Claude works with your own models, datasets and diagrams, using
the same conventions and checks as the app. It works on every plan: free
accounts get 50 tool calls a day, the new **Agent** plan (US$2/month, for using
Reliafy from your AI agent) gets 2,000 a day and more storage, and Pro has no
daily limit and fits models in Reliafy — on Free and Agent, Claude fits locally
with SurPyval and saves the result. You can see and revoke Claude's access any
time under Settings → Connected apps. Setup, the plans and the full list of
tools are in the [API docs](/api-docs#mcp).

## Download any diagram as Python

Every reliability block diagram now has a **Download as Python** button. It
gives you a standalone script that rebuilds the diagram with the open-source
[SurPyval](https://github.com/derrynknife/SurPyval) and
[RePyability](https://github.com/derrynknife/RePyability) libraries — every
block's distribution, repair time, voting gate, standby and common-cause group
spelled out — and runs the same calculation. The numbers match what Reliafy
shows you.

Use it to check the maths, drop a diagram into your own pipeline, or run a
bigger analysis on your own machine. It works on your diagrams, shared ones,
the samples, and public links, on every plan.

## Availability results you can keep and share

Running an availability simulation on a repairable diagram now **saves the
result with the diagram**. Open it again, or send someone a public link, and
they see the result straight away — no waiting for a simulation to rerun.
Change anything that matters and Reliafy knows the saved result is out of date.

## Availability simulation is now part of Pro

Availability simulation runs thousands of Monte-Carlo replications, so it's
now part of **Pro** (or available with purchased credits). Everyone can still
build and validate repairable diagrams, view saved results, and see the
worked instrument-air example in full. And because the maths is open source,
anyone can download a diagram and run the simulation themselves for free.

## Fixes

- Reliability charts now size their time axis to the system rather than its
  longest-lived part, so a very reliable component no longer squashes the
  curve against the left edge.
