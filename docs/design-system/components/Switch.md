# Switch

An on/off switch: a button with `role="switch"`, a track and knob, and its label beside it. On: the track fills `accent`, knob `text-on-fill`.

For a setting that applies at once (an alert on or off), not for a form field that waits for Save — use a checkbox there.

## Props

`checked`, `onChange(next)`, `label` (the visible label), `ariaLabel` (when the label alone is unclear), `disabled`, `title`, `className`.
